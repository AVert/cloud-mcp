# Changelog

## 2026-10-12 — rate limiting
- Клиент: семафор `SWEB_MAX_CONCURRENCY` (4) + пауза `SWEB_MIN_INTERVAL` (0.2 с) между стартами запросов.
- Повторы с экспоненциальной паузой (`SWEB_MAX_RETRIES`=3, `SWEB_BACKOFF_BASE`=0.5, потолок 30 с, `Retry-After` учитывается): HTTP 429 — для любых методов (запрос отклонён до обработки); 502/503/504 и сетевые ошибки — только для read (исход write/destructive/paid неизвестен, повтор мог бы задвоить заказ/удаление).
- Официальные лимиты SpaceWeb нигде не документированы — значения подобраны консервативно, настраиваются env.
